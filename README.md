# Matheos

Calculation documents for structural engineers: a plain-text file mixing Markdown prose
with unit-aware math statements, evaluated top to bottom, shown live in a minimal editor
and printed as a clean PDF report with KaTeX-style math.

Status: **wayfinding**. Nothing runs yet. The v1 spec is being charted as decision
tickets on this repo's issue tracker; the map is the issue labelled `wayfinder:map`.

- `docs/research/` — primary-source research the spec rests on.
- `CONTEXT.md` — the glossary.
